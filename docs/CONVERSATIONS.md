# 对话历史与图文匹配（v11，2026-11-17）

## v12 更新（2026-11-18）

新对话的招呼与趣味提示居中，不作为历史或游客消息；“正在想一想”在当前问题之后，位于同一滚动流。助手回复正常段落流，不保留旧容器的 pre-wrap 或重复内边距。来源紧凑罗列，保持链接和可点击的资料缩略图，每个景点仅一张代表图，不再横向堆积大卡。

铁塔的简单讲解和画面工具统一进入真实全景，文字/单句语音/实时语音一致，后来的简单工具不覆盖全景。文字保持安静，显式点播放后逐句讲解；语音镜头随实际音频句首。通话连接后只主动问候一次；上下文刷新不重复，不创建伪造游客字幕。当前供应商权限阻塞与回归结果见 [v12 记录](V12_PLAN.md)。

真实公网文字铁塔全景与固定 TTS 镜头同步、中断已验证；本轮实时模型初始化被 `AccessDenied.Unpurchased` 拒绝，只有隔离通话协议验证通过，不能称实时交流现已恢复。未更换模型/凭据，权限错误在界面明确提示开通权限或额度。

## 交互规则

- 打开文字窗口或点击“新建对话”时创建空白草稿，显示一句简短招呼，不自动聚焦输入。招呼仅为空态界面，不伪造游客消息或污染模型上下文。
- 对话标题右侧为历史、新建和关闭；语音/伴游状态菜单也有“历史对话”。
- 文字、实时语音字幕及伴游到点讲解都进入统一历史。语音流增量按消息 ID 更新，不为每个字幕片段创建一行；打断状态同步更新。
- 全景逐句讲解单独归档实际固定讲稿：播放边界确认上一句播完，成功播完后保存全文；中断时只保留已确认完整播完的句子并标明当前句未播完。不把提前收到的全文或被静音的模型总结当作已播内容。
- 历史仅为可点击列表或“暂无历史对话”。点击一条立即恢复正常文字窗口，不设详情中转或“继续”二次入口。从伴游选择历史时先切到交互再恢复，不把伴游本身变成文字模式。保存规则收在可展开说明中。
- 打开新窗口不清除地图、全景和已调整的分屏比例。只有点击输入才进入全屏编辑，发送后恢复分屏。

## 保存与标题

`src/guide/conversation-history.js` 用当前浏览器 `localStorage` 的 `virtour.conversations.v1` 保存。不是登录账户或跨设备云同步；清理浏览器数据会移除记录。最多 80 段、单段 500 条，接近容量时优先淘汰旧会话。私密模式/空间不足时不阻断交流，历史窗口说明未持久保存。

模型上下文仍限制最近 12 条，独立历史按稳定消息 ID 合并，避免长对话被上下文截断。界面展示完整当前对话，复用未改变的图片/消息节点，不在隐藏的语音界面反复重建整个文本列表。

标题先由当前内容生成本地主题，再异步调用 `/api/conversations/title`，使用现有文字模型拟定短标题。只在完整回答后请求，有限频率更新，不阻塞语音或回答。接口只接受最多 8 条、每条 1400 字的 user/assistant 数据，不提供工具或系统角色输入；标题最长 24 字。模型不可用则保留本地主题。迟到结果按会话 ID 和内容签名校验，不覆盖新会话或已改变的主题。

## 图文联动

- 交互实时语音的铁塔简单讲解自动进入可用全景，固定逐句讲稿与镜头同步；迟到的图片工具不覆盖带看。伴游简单讲解、其他景点和文字问答关联本地 POI 图片。无完整全景的地点不伪造 360° 素材。
- 服务端确认 `arrival:started` 后，伴游展示该景点图片，并把图片关联到同一话轮的讲解记录。模拟预览、被拒绝/过期的到点事件不展示新讲解。
- 图文匹配按话轮隔离，不因为页面默认选择铁塔，就给闲聊、感谢或下一轮套用铁塔图片。
- 用户明确不切换画面时不自动导航；匹配图片仍可显示在文字记录内。详细全景不被后续简单讲解覆盖。
- 本地图片从已知 POI ID 与 `introductionPhotos` 取。后端新增 `search_web`（Tavily）；只有成功搜索结果可产生联网来源/图片卡，包含来源链接和资料图标签，不冒充园内实拍。`TAVILY_API_KEY` 未配置时明确不可用，不向前端泄露密钥或让模型提交任意抓取 URL。
- 交通、餐饮等本地知识结果也生成对应资料卡；没有可信图片时不配无关景点。网页图片采用 HTTPS、公网域名、不发送 Referer，加载失败时保留资料文字。记录中的资源同样清洗。
- 助手当前及历史回复支持安全 Markdown：粗体、列表、段落、标题、引用、代码、链接和表格。通过 DOM 文本节点构建，不执行原始 HTML，不加载 Markdown 内模型编造的图片或危险 URL。游客输入保留纯文本。
- 语音窗口有本轮图片/资料条；文字窗口直接跟随回答展示。资源按话轮隔离，用户可主动收起。
