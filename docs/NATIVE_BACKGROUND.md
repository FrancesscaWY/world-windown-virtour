# iOS 原生锁屏伴游基础（v11）

## 范围与当前状态

用户已选择原生后台音频方案。仓库新增 `native/ios/` 的 SwiftUI + WKWebView 壳、原生音频队列与定位代理，网页通过 `src/services/native-companion.js` 接入。**当前为待 macOS 构建和真机验收的原生实现基础，不是已签名/已安装的 App，也不改变 Safari 的后台权限。** 当前 Linux 环境没有 Xcode/iOS SDK，未执行原生编译。

- 原生伴游不保持后台实时收音，不通过静音音频、Web Worker 或无限 `beginBackgroundTask` 伪装保活。
- 先在前台缓存本次最多 12 个可信景点的固定解说音频，完成后使用 `AVAudioSession.playback`、`AVAudioPlayer` 连续播放。系统媒体中心支持暂停、继续和停止。准备完成前锁屏可能导致下载被终止，应返回前台重试。
- 默认模拟位置对应**连续解说模式**，按队列播放，不说游客已经到达这些景点。开启设备来源后使用原生 CLLocationManager，以真实定位触发缓存讲解。
- 后台定位需系统授权，准确度、新鲜度、35 米触发半径与同次访问去重均有约束；地图坐标仍来自已标注的 OSM 地点，不等于精确实测入口。
- 来电、音频中断和耳机拔出时暂停，用户显式恢复；不擅自重播。关机、强制退出应用、系统终止、撤销权限不能保证继续运行。
- 只记录固定稿完整播放成功的文字，中途停止记为打断；原生状态暂存本机，页面回前台同步到原会话，不插入新会话或伪造游客语音。

## 构建

需要 macOS、Xcode 15+、XcodeGen、Apple 开发/测试签名及真实 iPhone。最低 iOS 16。

1. 在 `native/ios/project.yml` 中核对 `GuideBaseURL`（必须为有效可信 HTTPS）和 Bundle ID。
2. 在该目录执行 `xcodegen generate`，生成 `VirTour.xcodeproj` 与 Info.plist。
3. 用 Xcode 打开，选择开发团队及真机，检查 Background Modes 中 Audio 与 Location，构建安装。
4. 若需要分发，使用 TestFlight/已批准的企业分发等合法方式；代码本身不会自动生成可安装包。

壳仅允许主帧、指定 HTTPS origin 调用原生桥；外部来源链接交给系统浏览器。下载只请求配置站点的 `/api/tts`，拒绝重定向，限制长度、响应大小和 PCM 格式。模型密钥仍只在服务器，不进入 iOS 项目。

## 必须完成的验收

- 模拟器和真实 iPhone 编译运行；iOS 的权限回调、WKWebView 信任源/端口及音频会话。
- 首次授权、拒绝/仅使用期间/始终允许、精度降低、定位超时和离开园区。
- 下载完成后锁屏至少 10 分钟、耳机与蓝牙切换、来电/闹钟中断、前后台连续切换。
- 系统媒体控制与停止后音频会话/定位的释放；无任何意外麦克风采集。
- 网络断开后的已缓存队列、准备期间断网、下载超时、快速开始/停止/重开，不能串播旧队列。
- 回前台的历史去重、完整与中断记录、切换其他对话后不串入。

Node 单元测试和浏览器原生桥夹具只能验证 JS 契约，**不能视作 iOS 后台播放已经通过**。Android 尚未建立原生客户端；如需 Android，需要前台媒体服务及独立权限/设备验收。
