## 实现细节

- `experience-v12.css`：交互为石墨灰/冷白，伴游为核桃棕/暖砂白；两套组件共享排版，不再使用红蓝主按钮组合。四分类保持独立强调色。搜索有实有素材缩略图、主题捷径与区域筛选；推荐为低矮单行条。
- 新对话招呼居中，提示不进入模型上下文；来源变成紧凑行，最多一张景点缩略图/地点，保留来源链接。等待提示位于当前用户问题之后，和消息一起滚动。覆盖旧 CSS 的 pre-wrap 和段落内边距，避免大空行与短句折行。
- 静止模拟位置不再 30 秒失效；真实 GPS 仍检查新鲜度和精度。附近、详情直线距离、文字、录音与通话上下文共用当前坐标。路线后端从当前坐标关联既有手绘路网，包含起点到首站的一段；不伪造门口坐标、真实路程或耗时，无法关联则明确返回不可用。
- 路线沿途站点有亮边与起点标识，聚集标记在屏幕内错开并保留细引线，避免互相遮盖。伴游经过已知景点 35 米范围时留下小亮点；切模式、换来源或重置模拟起点会清空本次轨迹，点选浏览不制造途经记录。
- 地图仅保留现有 2D，过期 view/rotate 控制不能改变俯仰。总览不显示空的“全园”折叠泡。缩到 85% 以下进入已有 OSM 快照的周边地理概览，放大回手绘图；两种配准不强行叠加，不把城市道路拉伸成手绘道路。来源为现有 `world-window-osm-source.json`，生成脚本 `prepare-surroundings.mjs`，保留 OSM 署名，不新增外部瓦片请求。
- 铁塔简单介绍、画面工具与详细介绍共享全景策略。文字进入真实全景和热点文字，但不擅自出声；点“播放逐句讲解”后播报。语音通过实际音频边界驱动镜头与字幕，后来的简单图片工具不覆盖全景。伴游的显式铁塔问题也进入全景；被动到点提示仍保留地图。
- 交互通话连接后请求一次简短问候；上下文更新不重复问候，不伪造浏览器游客字幕。用户插话、点选或停止仍使旧响应失效。
- 导游选择避开输入栏、聊天、全景卡、热点、资料与路线标记的空位；空间不足时暂隐而非盖住文字。全景实际相机回调驱动屏幕跟随，不以固定计时假装跟随；允许用户拖动后保持手动位置。
- 模型约束：从已知当前位置安排具体游览顺序，不复述 R01 等内部标号，减少“参考资料显示/资料没查到”等口吻，保留必要的事实与时效限制。
